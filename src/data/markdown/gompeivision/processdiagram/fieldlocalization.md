# Field Localization

While GompeiVision provides field-relative pose estimates from AprilTag observations, the robot's primary localization system runs on the roboRIO. The robot continuously tracks its position using odometry derived from wheel encoders and a gyroscope, which provides smooth, low-latency updates suitable for real-time control. However, odometry alone accumulates error over time due to wheel slip, collisions, and other sources of drift.

To correct this drift, vision measurements generated by GompeiVision are fused with the robot's odometry using WPILib's Kalman filter-based pose estimator. The estimator combines high-frequency encoder and gyroscope data with lower-frequency vision observations to maintain an accurate estimate of the robot's position on the field. Each vision measurement is timestamped when captured, allowing the estimator to account for processing and network latency before incorporating the observation. This sensor fusion approach combines the responsiveness of odometry with the global accuracy of AprilTag-based localization, producing a robust field pose estimate that can be used for autonomous navigation, trajectory following, and automated scoring routines.
