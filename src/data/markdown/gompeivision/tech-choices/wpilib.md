### Why WPILib was chosen for GompeiVision

WPILib is the standard software library used in the FIRST Robotics Competition (FRC).

- **Robot Integration**: Using WPILib ensures native compatibility with FRC standards, making it straightforward to communicate between the coprocessor and the roboRIO.
- **Pose Fusion**: The pose estimation measurements generated by GompeiVision are formatted and transmitted using WPILib structures, allowing the roboRIO to easily fuse camera localization data with odometer and IMU inputs via the standard WPILib kinematics library.
- **Familiar Ecosystem**: Students can write their vision pipelines in a language and framework consistent with the primary robot control code.
