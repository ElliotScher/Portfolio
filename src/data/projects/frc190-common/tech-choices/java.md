### Java for FRC 190 Codebases

Java is used for all FRC 190 codebase projects because it is the most common language in FRC, providing a robust, object-oriented framework for robot programming:

* **FRC Standard**: As the most widely adopted programming language in the FIRST Robotics Competition, Java ensures access to extensive community resources, vendor APIs, and documentation.
* **WPILib Command-Based Paradigm**: Leverages the official Command-Based framework to structure robot code into self-contained Subsystems and cooperative Commands.
* **Object-Oriented Design**: Encourages modular, clean, and testable codebase structures that simplify collaboration across team members.
