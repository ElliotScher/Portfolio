\textbf{Park Vision --- WPI Interactive Qualifying Project with the National Park Service}
\begin{itemize}
  \item Co-developed a computer vision pipeline (YOLO detection, IOU entity tracking, pose-based direction, license-plate OCR) that automates visitor-use monitoring from Acadia National Park trail-camera photos and video for the National Park Service.
  \item Achieved 98\% accuracy on vehicle counts and 93\% accuracy on license plate reads against manually collected ground truth at a live parking lot deployment.
  \item Built and packaged a cross-platform PySide6 desktop application backed by a per-folder SQLite/SQLAlchemy database, with automated multi-OS builds and releases via GitHub Actions.
\end{itemize}
