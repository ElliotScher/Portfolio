### Java for FRC Shared Codebase

Java was selected as the primary language for FRC Team 190's robot software to leverage WPILib's native Command-Based framework and support clean object-oriented architecture:

* **Type Safety & Enums**: Strong typing prevents run-time configuration mismatches. Multi-robot configurations are safely mapped using Java Enums and Pattern-Matching switch statements.
* **Standard Tooling**: The FRC software ecosystem, including WPILib and vendor libraries, has extensive native support for Java, ensuring stable development pipelines.
* **Ease of Access**: FRC students are widely introduced to Java through AP Computer Science, enabling rapid onboarding of new programmers.
