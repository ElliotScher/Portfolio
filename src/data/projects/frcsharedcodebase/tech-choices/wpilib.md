### WPILib for FRC Shared Codebase

WPILib is the standard software library used for FIRST Robotics Competition:

* **Command-Based Framework**: Facilitates a clean state-machine architecture by separating subsystems (hardware interfaces) from commands (autonomous or driver-controlled operations).
* **Physics Simulation**: Provides hardware-independent classes (e.g., `ElevatorSim`, `SingleJointedArmSim`, `DrivetrainSim`) for emulating physical interactions on standard developer PCs.
* **Hardware Interoperability**: Integrates sensors, controllers, and dashboards through a unified driver station communication layer.
