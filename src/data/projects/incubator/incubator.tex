\textbf{Distributed Optical Density Measurement and Automation System}
\begin{itemize}
  \item Developed a distributed laboratory automation platform for monitoring optical density measurements in biological samples.
  \item Implemented a Raspberry Pi-based application layer for data visualization, experiment management, and system coordination.
  \item Designed embedded microcontroller software for real-time actuator and sensor control within the measurement system.
  \item Integrated serial UART communication between subsystems to support automated experimental workflows.
\end{itemize}
