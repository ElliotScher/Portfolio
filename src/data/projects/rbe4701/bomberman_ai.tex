\textbf{Bomberman AI: Planning \& Reinforcement Learning}
\begin{itemize}
  \item Built a Python game agent that combines A* path planning with a precomputed MDP value-iteration policy to escape monsters, reaching an 86\% overall escape rate.
  \item Developed an approximate Q-learning agent with a state machine and safety shield that learns where to bomb walls, escaping in 89.8\% of over 600,000 test games.
\end{itemize}
