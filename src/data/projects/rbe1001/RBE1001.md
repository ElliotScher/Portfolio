## Summary

**WPI RBE 1001: Introduction to Robotics** details the development of an advanced autonomous mobile manipulator programmed utilizing the [VEX V5 Robotics System](https://www.vexrobotics.com/v5) Python API. The robot integrates a full sensor suite to achieve closed-loop sensor-fused odometry, proportional-derivative (PD) line-following, sonar distance regulation, vision-based object centering/servoing, and a complex 11-state state machine orchestration to harvest and classify fruit autonomously.

***

## Context: The VEX V5 Robotics Platform

The VEX V5 system serves as the physical hardware base, pairing direct motor encoder feedback with a diverse array of analog and digital sensors. Developing in Python on this platform teaches students to manage real-world constraints such as motor torque saturation, sensor noise, carpet slippage, and battery level fluctuations.

## System Design: Autonomous Fruit Harvester

The fully autonomous harvester is designed to navigate a grid field, identify fruit classes, lift the collection bucket to dynamic heights, capture the fruit, and sort them into designated baskets.

### Omnidirectional X-Drive Drivetrain

The robot utilizes an omnidirectional X-drive (Mecanum) drivetrain configuration consisting of four wheels mounted at $45^\circ$ angles. This mechanical setup enables holonomic movement - allowing translation in any direction (forward/backward, sideways strafing, or diagonal driving) independent of rotational orientation:

* **Mecanum Kinematics**: The drive control code translates desired translation velocity ($v_{trans}$), travel angle ($\alpha$), and rotational velocity ($\omega$) into target RPM values for four angled wheels. Speed projections are calculated using vector projection equations:
  $$FrontLeft = \omega_{rot} - (x - y)$$
  $$FrontRight = \omega_{rot} - (x + y)$$
  $$BackLeft = \omega_{rot} + (x + y)$$
  $$BackRight = \omega_{rot} + (x - y)$$
* **Field-Oriented Control**: An Inertial Gyro sensor tracks the robot's absolute heading. By adjusting the target movement vector based on this heading angle ($\alpha_{field} = \alpha_{input} + \theta_{gyro}$), the robot translates relative to the field coordinates rather than the robot's physical front nose.

### Sensor Fusion & Advanced Algorithms

#### 1. Vision-Based Servoing & Object Centering
The robot interfaces with a VEX Vision Sensor configured with signatures for **LIME**, **LEMON**, and **TANGERINE**.
* **Horizontal Correction (Strafe):** Dynamically adjusts lateral velocity proportional to the target's horizontal pixel offset from screen center ($160$ px):
  $$e_x = 160 - centerX$$
  $$v_y = e_x \cdot K_{p,vision}$$
* **Vertical Correction (Forward):** Regulates forward velocity proportional to the vertical pixel offset from camera target ($106$ px):
  $$e_y = 106 - centerY + 30$$
  $$v_x = e_y \cdot K_{p,vision}$$

#### 2. Cross-Axis Drift Compensation
Strafing and forward motion trigger complex wheel slippage on physical carpets. The odometry updates are adjusted dynamically based on travel angle:
$$\text{driftCompPercentage} = \left|\cos(2\theta_{travel} \pmod \pi)\right|$$
This scaling factor adjusts the calculated coordinates to counteract coordinate drift when driving diagonally or strafing.

#### 3. PD Line-Following Control Loop
Steers the robot along grid lines using two analog reflectance sensors in a Proportional-Derivative (PD) loop:
$$e(t) = Reflectivity_{left} - Reflectivity_{right}$$
$$u_{strafe} = e(t) \cdot K_p + \frac{e(t) - e(t-\Delta t)}{\Delta t} \cdot K_d$$
If the robot drifts off-line, it tracks the last sensor triggered to apply immediate corrective strafing and re-acquire the path.

#### 4. Sonar-Based Dynamic Lift Tuning
* **Stall Homing:** The lift homing sequence runs the lift motors in reverse until a torque/current threshold ($>0.3$ N·m) is exceeded, signifying contact with mechanical hard stops.
* **Adaptive Height Detection:** A vertical sonar sensor measures fruit suspension height, dynamically adjusting lift height targets:
  - **High Fruit:** $\approx 0.234$ m -> Moves to High height ($5.2$ motor turns).
  - **Mid Fruit:** $\approx 0.126$ m -> Moves to Mid height ($3.0$ motor turns).
  - **Low Fruit/Default:** Otherwise -> Moves to Low height ($0.2$ motor turns).
