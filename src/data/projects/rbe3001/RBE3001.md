## Summary

**Robotic Arm** is an autonomous pick-and-place sorting system developed for WPI's RBE 3001 (Unified Robotics III) lab. The system uses the OpenManipulator-X (OMX) 4-DOF serial robotic arm platform coupled with a post-mounted USB camera to identify, locate, grasp, and sort colored spheres in real-time. Built entirely in MATLAB R2025a, the software pipeline integrates forward/inverse kinematics using Denavit-Hartenberg parameterization, cubic and quintic trajectory spline generation, differential kinematics for singularity detection, and a full computer vision pipeline (camera intrinsic/extrinsic calibration, HSV color masking, centroid detection, and perspective correction).

***

## Context

In robotic manipulation, coordinate translation between perception sensors and physical actuators is a fundamental requirement. An autonomous sorting robot must be able to convert raw 2D pixel coordinates from a distorted webcam feed into high-accuracy 3D coordinates in the robot's local base coordinate frame, plan smooth trajectories to avoid joint stress, and execute precise actions without human intervention. 

To address these requirements, this project implements a complete perception-to-action pipeline using the OMX arm. The robot operates over a checkerboard board workspace, detecting colored spheres (red, yellow, green, blue) and placing them into designated color-coded receptacles.

### Analytical and Differential Modeling

To achieve robust control, the system must mathematically model the physical constraints of the arm:
* **Forward Kinematics**: Translating joint coordinates $\vec{\theta} = [\theta_1, \theta_2, \theta_3, \theta_4]^T$ to the 3D position and orientation of the end effector.
* **Inverse Kinematics**: Solving for the necessary joint angles to reach a target $(x, y, z)$ position, under geometric constraints.
* **Manipulator Jacobian**: Analyzing the differential relationship between joint velocities and Cartesian end effector velocities ($\vec{v} = J(\vec{\theta}) \dot{\vec{\theta}}$) to predict and avoid kinematic singularities.

The system was designed and verified with the following parameters and constraints:
* Must communicate reliably with the Dynamixel servos at a high control frequency using the Dynamixel SDK.
* Must achieve sub-centimeter sorting accuracy across a wide workspace.
* Must detect and avoid kinematic singularities where the Jacobian determinant approaches zero.
* Must calibrate the camera lens distortion to prevent visual localization errors.
* Must compensate for sphere 3D height parallax projection offsets.

## Process

Throughout the RBE 3001 (Unified Robotics III) course, the labs progressed systematically to build a complete perception-to-action robotic pipeline:

* **Hardware & Communication**: Established Ubuntu-to-Dynamixel serial communication using MATLAB and the Dynamixel SDK to command and read joint angles in real time.
* **Forward & Inverse Kinematics**: Derived DH parameters for the 4-DOF OpenManipulator-X arm and solved inverse kinematics geometrically using decoupling and coordinate constraints.
* **Trajectory Generation**: Planned smooth paths between operational space coordinates using cubic and quintic splines to optimize velocity profiles and minimize motor strain.
* **Differential Kinematics**: Formulated the analytical Manipulator Jacobian for coordinate velocity mapping and implemented singularity detection to prevent unstable controls.
* **Camera Calibration**: Calibrated a fisheye camera's intrinsic parameters to correct lens distortion and solved extrinsic transformation matrices to map camera coordinates to the robot base frame.
* **Computer Vision**: Developed HSV color-masking and centroid detection pipelines, including a parallax height correction algorithm to locate sphere positions accurately.
* **Closed-Loop Integration**: Unified all systems into a fully autonomous state machine capable of sorting colored spheres with a 97% success rate.
