\textbf{Vision-Based Robotic Grasping}
\begin{itemize}
  \item Built a ROS 2 point cloud pipeline in C++ and PCL that merges multi-view depth data, segments objects, and synthesizes two-finger grasps.
  \item Integrated grasp planning with MoveIt to execute collision-free grasps on a Kinova Gen3 lite arm in simulation and on hardware.
\end{itemize}
