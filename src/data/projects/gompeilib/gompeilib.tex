\textbf{GompeiLib Robotics Framework}
\begin{itemize}
  \item Developed a modular robotics software framework for FIRST Robotics Competition robots in Java.
  \item Implemented reusable subsystems for drivetrain control, vision integration, sensor management, and autonomous operation.
  \item Designed abstractions to simplify robot code development and improve maintainability across competition seasons.
\end{itemize}
