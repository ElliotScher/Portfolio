### Why CMake was chosen for GompeiVision

Since GompeiVision needed to run on a wide variety of hardware, I chose CMake as the project's build system.

- **Cross-Platform Consistency**: CMake is the de facto standard build tool for modern C++ projects and provides a consistent way to manage dependencies, compiler settings, and platform-specific configuration.
- **Portability**: By using CMake, the same source code can be built on everything from a Raspberry Pi to a desktop Linux machine with minimal changes.
- **Industry Alignment**: This makes the project easier for future students to understand and extend, as CMake is commonly used throughout industry and open-source robotics projects.
