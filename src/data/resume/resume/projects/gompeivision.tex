\textbf{FRC Vision Localization System}
\begin{itemize}
  \item Developed a multi-camera vision localization system for FRC robots using AprilTag pose estimation.
  \item Implemented persistent Linux camera identification using udev rules and physical USB path mapping.
  \item Optimized low-latency pose publishing between coprocessor and roboRIO using NetworkTables.
\end{itemize}
