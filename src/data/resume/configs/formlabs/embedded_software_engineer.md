# Embedded Software Engineer — Formlabs

Full-Time · Somerville, MA

## About Formlabs

Formlabs builds the tools that make it possible for anyone to bring their ideas to life, from cutting-edge products to life-saving medical devices. Its 3D printing technology powers innovation at more than 50,000 industry leaders worldwide, including Apple, Google, Tesla, New Balance, and NASA.

## About the Role

Software is at the heart of all aspects of Formlabs products, bridging the transition from digital models to beautiful physical form in 3D printing. The Embedded team is the essential component that ties software, hardware, and electronics together, pushing the limits of 3D printing — they design and implement Formlabs' firmware.

**The tech stack:** C++, Python, Embedded Linux, and the occasional dip into JavaScript.

## You

- Have professional experience writing code that lives on hardware products in the consumer, medical, defense, or industrial space.
- Program with modern languages used for embedded software stacks, ideally in C, C++, and/or Python.
- Easily implement common embedded software architecture patterns for things like filtering, control loops, and remote procedure calls.
- Architect code that your fellow software engineers are excited to use and re-use.
- Have familiarity and comfort debugging complex hardware and software interactions.
- Distill complex things simply when communicating with non-software stakeholders.

## The Job

- Design, build, test, and ship development tools and prototype code for R&D engineers working on new, unlaunched Formlabs products.
- Design, build, test, and ship code for new printer features to the tens of thousands of Formlabs devices in the field.
- Ensure code re-use with a strong focus on maintainability, testing, and CI.
- Collaborate with different stakeholders (product managers, designers) to ensure the right features are built for customers, existing and future.
- Work in a product-focused, agile environment onsite in the Somerville, MA office.

## Compensation

$110,000–$150,000/yr.
