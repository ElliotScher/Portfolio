# Systems Software Engineer I — CherishHealth

## Overview

We seek a curious, motivated Systems Software Engineer I to help build and optimize the core software platform behind our next-generation, radar-based sensing device. In this role, you will work deeply within systems software — focusing on C/C++, Linux, embedded platforms, and performance-critical development — to learn how to deliver reliable alerts, real-time data processing, and highly efficient system behaviors where performance and reliability truly save lives.

## What You'll Do

- Contribute to a multidisciplinary team responsible for the development, efficiency, and robustness of our core systems.
- Write C/C++ code for foundational system services, including daemons, schedulers, and workers, under the guidance of senior engineers.
- Get hands-on experience with Linux, embedded OS environments, and real hardware.
- Learn to build and maintain stable, versioned APIs and communication layers between system components.
- Adopt performance profiling and optimization techniques to ensure maximum runtime efficiency.

## Cross-Functional Collaboration

Your work will span the low-level software lifecycle — collaborating closely with senior systems engineers, firmware developers, machine learning scientists, and hardware teams to define hardware-to-software interfaces and robust failure-mode behaviors. As you develop your technical foundation, you will play an active role in testing, debugging, and validating production systems to ensure exceptional reliability and production hygiene, establishing a clear path toward owning meaningful production systems as you grow.
