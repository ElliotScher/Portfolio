# Backend Software Engineer — BeaconFire

Full-Time · On-site at client locations (location varies by client project)

## About the Opportunity

BeaconFire is hiring Entry-Level Backend Software Engineers with a foundation in programming and object-oriented development. Designed for recent graduates and early-career candidates who want to build their skills in backend software engineering, Java, and Generative AI. Academic projects, coursework, internships, and personal programming experience are all relevant — extensive professional experience is not required.

Java experience is preferred, but candidates with backgrounds in C++, C#, Kotlin, Python, or other OOP languages who are interested in developing their Java skills are also welcome.

## What You'll Do

- Develop and maintain backend applications and services.
- Build and work with REST APIs, databases, and backend application components.
- Apply object-oriented programming, data structures, and problem-solving skills to software development.
- Develop software using Java and modern backend technologies such as Spring Boot.
- Write clean, maintainable, and well-tested code.
- Debug applications and contribute to performance and reliability improvements.
- Participate in code reviews, testing, Agile development, and the software development lifecycle.
- Work with relational and NoSQL databases and SQL.
- Explore and integrate Generative AI and LLM technologies into software applications.
- Work with AI technologies and concepts such as RAG, embeddings, vector databases, and AI-powered applications.

## Required Qualifications

- Bachelor's or Master's degree in Computer Science, Software Engineering, Information Technology, or a related field.
- A foundation in programming and object-oriented programming (OOP).
- Experience with at least one programming language, such as Java, C++, C#, Kotlin, Python, or a similar language.
- Understanding of common data structures and programming fundamentals.
- Basic knowledge of relational databases and SQL.
- Strong problem-solving skills.
- Ability to communicate effectively and work collaboratively.
- Willingness to learn Java and develop backend software engineering skills.

## Preferred Qualifications

- Java or Spring Boot experience.
- Backend development or REST API experience.
- Experience with SQL, MySQL, or PostgreSQL.
- Familiarity with microservices or other backend technologies.
- Knowledge of Maven, Kafka, RabbitMQ, or similar technologies.
- Familiarity with Generative AI, LLMs, or AI-powered applications.
- Exposure to RAG, vector databases, embeddings, or related AI technologies.
- Internship or other software development experience.
